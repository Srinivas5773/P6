# Memory Match Pro - Ultra Feature-Rich Card Matching Application

A production-grade, zero-dependency, ultra-feature-rich **Memory Match** card-matching game built using Vanilla HTML5, CSS3, and ES6+ JavaScript.

## Features

- **6 Game Modes**: Classic Match, Triple Match, Time Attack, Quest Campaign (1,500 levels), Vs AI Opponent (4 difficulty tiers), and Zen Mode.
- **Dynamic Grid Sizes**: 2x2, 4x4, 6x6, 8x8, 10x10.
- **8 Visual Themes**: Cyberpunk Neon, Retro Synthwave, Fantasy Realm, Minimal Dark, Deep Space, Nature Zen, Candy World, and High Contrast Accessibility Mode.
- **Web Audio API Synthesizer**: Procedural sound FX (flips, matches, fanfares, timer chimes) and ambient background music generator.
- **HTML5 Canvas Particle Engine**: Match explosion sparkles, celebratory confetti cannons, and floating background particles.
- **Tactical Power-Ups**: X-Ray Peek, Freeze Time, Rearrange Shuffle, and Pair Magnet.
- **Progression & Analytics**: 17 unlockable achievements, XP level progression (Level 1-100), career statistics, and LocalStorage auto-save with JSON export/import.

## Requirements & Dependencies

- **Node.js**: v14.0.0 or higher
- Zero runtime external dependencies (Pure Vanilla JavaScript & HTML5 Standards).

## Installation

Clone the repository and navigate into the directory:

```bash
git clone https://github.com/Srinivas5773/P6.git
cd P6
```

Install development dependencies (for test runner):

```bash
npm install
```

## Running the Application

To launch the static web server on `http://localhost:3000`:

```bash
npm start
```

Alternatively, open `index.html` directly in any modern web browser.

## Build System

To execute the project build verification check:

```bash
npm run build
```

## Running Tests & Coverage

To execute the Jest unit test suite and generate coverage reports:

```bash
npm test
```
